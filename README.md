# 🏧 ATM Machine (Basic Python Project)

A simple command-line ATM simulation built using Python.

---

## 📌 Description

This project simulates basic ATM operations such as:

* Depositing money
* Withdrawing money
* Viewing transaction records

It is a **beginner-level project** focused on understanding program flow, functions, and file handling.

---

## ⚠️ Limitations

* No PIN authentication system
* No user account management
* Does not use Object-Oriented Programming (OOP)
* Limited error handling

This is a **basic implementation**, not a real-world ATM system.

---

## 📂 Project Structure

```id="8f1a2k"
ATM_machine/
│
├── main.py        # Controls overall flow
├── deposite.py    # Handles deposit logic
├── withdraw.py    # Handles withdrawal logic
├── record.py      # Stores transaction history
```

---

## ▶️ How to Run

1. Make sure Python is installed
2. Navigate to the project folder
3. Run:

```id="j2n4xp"
python main.py
```
